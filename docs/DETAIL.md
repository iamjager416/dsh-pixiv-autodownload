# Pixiv 自动下载

按你指定的画师自动下载 Pixiv 新作品，下过的自动跳过。

## 用法

设置 → **Pixiv 自动下载**：

1. 在输入框填画师 ID 或主页链接，回车加入
2. 需要每天自动跑，就设个时间并勾上「启用每日同步」
3. 想立刻跑一次，用「立即同步」

定时只在 DSH 运行时触发，DSH 没开的日子不会补跑。

## 保存位置

图片默认存到 `Pictures\pixiv\<画师名>-<画师ID>\<作品ID>_p<页>-<标题>.jpg`，目录和文件名都能在设置里改。

## 注意

- 不配 cookie 只能看到公开作品，R18 和私密作品需要 cookie
- 动图（ugoira）会跳过，不下载
- 它不知道你在硬盘上删了什么，删过的文件不会重下；要重下就先把记录清掉
